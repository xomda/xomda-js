# `demo/vue-blog` — Vue 3 SPA + xomda-generated Zod schemas

Two things in one folder:

1. A small **TypeScript harness** that builds a Blog domain model in code,
   persists it under `.xomda/`, and renders it with the repo-root xomda
   templates into `output/` (one Zod schema file per entity and per enum,
   colocated under `output/target/src/schemas/`).
2. A real **Vue 3 + Vite SPA** under `src/app/` that consumes the
   generated `AuthorSchema` to validate user input in a form. Reshape
   the model → regenerate → the SPA picks up the new validation.

## Layout

```
demo/vue-blog/
├── README.md
├── package.json                                ← TS harness + Vite SPA scripts
├── vite.config.ts                              ← Vite SPA (alias @generated → output/target/src/schemas)
├── vitest.config.ts                            ← two projects: node (harness) + dom (SPA)
├── tsconfig.json                               ← paths: @generated/* → output/target/src/schemas/*
├── .xomda/
│   └── model.json                              ← regenerated by `pnpm generate`
├── output/                                     ← [gitignored] xomda-produced schemas
│   └── target/src/schemas/
│       ├── {Author,Post,Comment}Schema.ts
│       └── PostStatusSchema.ts
└── src/
    ├── generate.ts, index.ts                   ← harness entry points
    ├── __tests__/blog.spec.ts                  ← node specs: schema + POJO assertions
    └── app/                                    ← Vue 3 SPA
        ├── index.html, main.ts, App.tsx, styles.css, types.ts
        └── components/
            ├── AuthorForm.tsx, AuthorList.tsx
            └── __tests__/AuthorForm.spec.tsx   ← dom specs: mount + emit + safeParse
```

## Run the SPA

```bash
pnpm --filter @xomda/demo-vue-blog generate      # one-off, fills output/
pnpm --filter @xomda/demo-vue-blog dev           # vite at http://localhost:5174
```

## Run the tests

```bash
pnpm --filter @xomda/demo-vue-blog test          # node + dom projects, one shot
```

Two projects run under one vitest:

- **node** — `src/__tests__/blog.spec.ts` regenerates and asserts on the
  produced Zod schemas (entity + enum).
- **dom** — `src/app/components/__tests__/AuthorForm.spec.tsx` mounts the
  Vue form in happy-dom and verifies it surfaces `AuthorSchema.safeParse`
  failures on bad input, emits a parsed `Author` on success, and resets
  after submit. This is the build-env test of the generated schema —
  template drift fails the mount.

Both flow through `pnpm test:demo` (which `pnpm test:all` chains).
